# AI Director 200-Point Implementation Status

The current Genei AI release delivers the **control-plane foundation** for the 200-point AI Director specification. The release includes typed Project Brain and Production Constitution contracts, the actual Python `ai_director.dag_compiler` invoked through a Node-to-Python bridge with a safe TypeScript fallback, explicit persisted project/scene/shot/job/QC state, capability routing, BYOH telemetry and installer foundations, media-worker planning, smallest-unit repair logic, a Director Console, and a real-time dependency dashboard.

The current dashboard upgrade adds backend DAG nodes and directed edges for project containment, shot-to-shot dependencies, shot-to-scene assembly, and shot/scene job execution. Failed or blocked jobs propagate a visibly highlighted downstream path so the operator knows which node must be repaired first. Operators can inspect field-level continuity boundaries, edit start/end handoff values, save a review state, approve a handoff, and pause, resume, cancel, or stop the durable Director job set from Video Studio or Director Console.

The Windows deliverable is a reproducible PyInstaller workflow rather than a falsely claimed binary. The Linux sandbox cannot generate a genuine Windows PE executable. A Windows workstation or the included GitHub Actions workflow must run `packaging/build_windows_exe.ps1` before `GeneiRunner.exe` exists as a downloadable artifact. The build emits a SHA-256 checksum and validates the packaged runner with `--help`.

The following higher-order items remain deliberately staged for later releases because they require real media analyzers, installed local models, external provider credentials, or a Windows signing certificate: full multi-format source extraction, persistent Project Brain version APIs, frame-level identity and optical-flow analysis, arbitrary open-source plugin installation, real ffmpeg execution on the paired workstation, and signed public EXE distribution. They are not represented as production-complete capabilities by the current UI.
