# Building the Android APK

Verified working. The APK in `app/build/outputs/apk/debug/` was produced by exactly these
steps, and its package, version and bundled assets were read back out of the finished file.

## What you need

| Tool | Version | Why |
|---|---|---|
| JDK | **21** | `capacitor.build.gradle` targets `JavaVersion.VERSION_21`. JDK 17 fails to compile. |
| Android SDK | platform 36, build-tools 36.0.0, platform-tools | `compileSdkVersion = 36` |
| Gradle | 8.14.3 | fetched by the wrapper |
| Node | **22 or newer** | the Capacitor CLI refuses to run on Node 20 |

## Steps

```sh
# 1. Build the web assets — Capacitor bundles them into the APK.
pnpm install
pnpm build                       # produces dist/public

# 2. Point Gradle at your SDK.
echo "sdk.dir=$ANDROID_HOME" > android/local.properties

# 3. Build.
cd android
./gradlew assembleDebug
```

The APK lands at `android/app/build/outputs/apk/debug/app-debug.apk`.

## If the network needs a proxy

The Gradle wrapper does not read `HTTP_PROXY`, so pass it to the JVM explicitly:

```sh
./gradlew assembleDebug \
  -Dhttps.proxyHost=<host> -Dhttps.proxyPort=<port> \
  -Dhttp.proxyHost=<host>  -Dhttp.proxyPort=<port>
```

## If `cap sync` cannot run

The Capacitor CLI requires Node 22+. On an older Node it exits with
`The Capacitor CLI requires NodeJS >=22.0.0`. `cap sync` only does two things, both
reproducible by hand:

1. **Copies the web build into the APK.** `cp -r dist/public android/app/src/main/assets/public`
2. **Writes the cordova plugins module.** This project uses no cordova plugins, so the
   module is boilerplate — see `android/capacitor-cordova-android-plugins/`.

## A known trap: the version-pinned module path

`android/capacitor.settings.gradle` is generated by Capacitor and, under pnpm, it pins the
**exact store path** of the Capacitor Android library:

```gradle
project(':capacitor-android').projectDir = new File('../node_modules/.pnpm/@capacitor+android@8.5.0_.../capacitor')
```

Upgrading `@capacitor/android` for a security fix therefore breaks the build with
`No matching variant of project :capacitor-android was found`, because the path still
names the old version. It now points at the stable location instead:

```gradle
project(':capacitor-android').projectDir = new File('../node_modules/@capacitor/android/capacitor')
```

**If you bump Capacitor again, re-run `cap sync` or re-apply that line.**

## Signing

`assembleDebug` signs with the Android **debug** certificate — correct for a debug build
and installable on any device, but it is **not** a release signature and must not be
published to a store. A release build needs `assembleRelease` with a keystore configured
in `android/app/build.gradle`.
